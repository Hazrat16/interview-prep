# Interview Prep Notes

Personal interview preparation notes, organized by domain and topic.

Use these as quick revision sheets: concept → example → interview Q&A (or polished spoken answers for career screens).

## Structure

```text
interview-prep/
├── database/     # SQL, transactions, locking, performance
├── career/       # Recruiter screens, ORC, STAR stories, LinkedIn
├── frontend/     # Coming soon
└── backend/      # Coming soon
```

## How to use

1. Pick a topic under a domain folder.
2. Read the concept / story first.
3. Practice the interview answers out loud.
4. Add new topics as separate markdown files under the right domain.
